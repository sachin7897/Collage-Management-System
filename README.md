# College Management System — PostgreSQL

A professional database management project designed to organize and analyze college-related data using **PostgreSQL and SQL**. This project demonstrates relational database concepts, data management, and analytical SQL queries through a structured college database.

## Project Overview

The College Management System is a database-only project developed to manage academic information, including students, faculty, departments, courses, enrollments, attendance, examinations, and results.

The project focuses on maintaining organized data, establishing relationships between entities, and extracting meaningful insights using SQL queries.

## Project Objectives

* Design and manage a structured college database.
* Organize academic information across multiple related tables.
* Store and manage student attendance, enrollment, examination, and result records.
* Perform data analysis using SQL queries.
* Retrieve and review records from multiple database tables.
* Demonstrate practical knowledge of PostgreSQL and relational database management.

##  Technologies Used

* **Database:** PostgreSQL
* **Database Management Tool:** pgAdmin
* **Query Language:** SQL
* **Data Format:** CSV
* **Version Control:** Git and GitHub


##  Database Modules

| Module     | Description                              |
| ---------- | ---------------------------------------- |
| Student    | Stores student-related information       |
| Department | Organizes college departments            |
| Course     | Maintains course information             |
| Faculty    | Manages faculty records                  |
| Enrollment | Stores student course enrollment records |
| Attendance | Maintains student attendance records     |
| Exam       | Stores examination information           |
| Result     | Maintains student examination results    |
